From pip install to a leaderboard entry.

The path is identical for every track. Change the track flag, swap the model, and the rest of the pipeline stays the same.

First install to first submission~ 15 minutes (toy split)
Full warm-up training run2 – 6 GPU-hours
Minimum hardwareCPU works · 8 GB GPU recommended
  1. 01
    INSTALL

    Install neuralbench.

    ~ 60 seconds · pip

    pip install neuralbench pulls in the benchmark runner, task registry, and evaluator; the datasets and models extras add dataset downloading (EEGDash) and the baseline model zoo (Braindecode). On first run, set DATA_DIR, CACHE_DIR and SAVE_DIR in ~/.neuralbench/config.json.

    Python≥ 3.12
    PyTorch≥ 2.2 (CUDA optional)
    Config~/.neuralbench/config.json
    Disk~ 4 GB for cached tasks
  2. 02
    DATA

    Download a track's data.

    streamed BIDS · seed corpora

    EEGDash streams the BIDS layout; only the recordings you reference are downloaded. Downloads land in the DATA_DIR of your NeuralBench config; preprocessed data is cached in CACHE_DIR and reused on every later run. The figures on the right are the full seed corpora per track — a warm-up split pulls only a fraction of that.

    Track 1 (EEG-to-IMG)116 GB
    Track 2 (BCI)419 GB
    Track 3 (Sleep)439 GB
    Track 4 (EMG)239 GB
  3. 03
    TRAIN

    Train a baseline.

    2 – 6 GPU-hours · warm-up split

    Every track ships at least one baseline you can train with a single neuralbench eeg <task> -m <model> call. Task and model names come from the registry: from neuralbench.registry import TASKS, ALL_MODELS.

    Default modelEEGNet · 0.04 M params
    OptimizerAdamW · cosine schedule
    SeedFixed by config
  4. 04
    SCORE

    Score locally with the official evaluator.

    ~ 1 minute · local

    The evaluator is the exact code we run on Codabench. Run the task locally first with neuralbench eeg <task>; the run writes a predictions Parquet with hyperparameters and the git SHA of your model code for the audit phase.

    Metric (T1)Top-5 retrieval accuracy
    Metric (T2)Balanced accuracy
    Metric (T3)W-bMAE on onset (s)
    Metric (T4)Character error rate
  5. 05
    SUBMIT

    Upload to Codabench.

    ~ 30 seconds · web UI or API

    Drop the submission.parquet on the Codabench page for your track. The daily submission cap, the best-of-last-five ranking and the reproducibility audit are rules, not start-kit details: read them on the Rules & FAQ page before your first upload.

    PlatformCodabench

Your first baseline, in three commands.

The Track 2 BCI example works in Python or the CLI. The same pattern applies to every track: load with EEGDash, train with Braindecode, score with NeuralBench. Swap the task and the model; the rest of the pipeline stays the same.
